## Overview
A command-line **Expense Tracker** built in Python that allows users to record daily expenses, categorize spending, view detailed summaries with percentage breakdowns, and persist data locally using JSON.

## Features
- **Add Expenses:** Record title, category, amount, and automatic timestamp.
- **View History:** Clean tabular view of all logged expenses.
- **Category Summary:** Calculates total spending and category-wise percentage breakdown.
- **Delete Records:** Remove entries by ID with automatic re-indexing.
- **Persistent Storage:** Saves all records automatically to `expenses.json`.
